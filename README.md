## Project Title
CampusCart — The Student's Marketplace

## Platform Used
**Wix** (built using the Wix Editor with Wix Stores and Aria AI site generation, then customized manually)

## Project Description
CampusCart is an online store designed for university students to conveniently buy affordable academic supplies, dorm essentials, and apparel without leaving campus. It solves the problem of students needing quick, budget-friendly access to daily necessities amid tight schedules. This project transforms the UI/UX design created in Figma (Assignment IV-a) into a live, functional e-commerce website.

## Features Implemented
- **Homepage** – Store name (CampusCart), hero banner ("The Student's Marketplace"), welcome/mission message, and a "Shop Now" call-to-action
- **Category Browsing** – Essential Categories section (Academic Supplies, Dorm Essentials, Apparel) with "Shop All" links
- **Product Page** – Trending Campus Essentials product grid with 5+ products, images, names, and prices (e.g. Collapsible Silicone Flask, Glass Sport Infuser, Double Wall Insulated Bottle, Modular Grid Pad, Spiral Notebook)
- **Add-to-Cart Functionality** – Each product includes a working "Add to Cart" button (via Wix Stores)
- **Promotions Section** – "Student Deals" banner with a "Shop Sale" call-to-action
- **About/Mission Section** – Description of CampusCart's purpose and value to students
- **Footer** – Contact details (email, phone, address) and legal links (Privacy Policy, Terms of Service, Shipping & Returns, Security)

## Accessibility Considerations
- Clear, high-contrast headings and body text
- Consistent navigation (Home / Shop) across the site
- Logical page structure with descriptive section headings
- Readable font sizes throughout product and text sections

## Challenges Faced
- Google Sites was initially attempted but lacked the flexibility (custom colors, real input fields) needed to match the Figma design, so the project moved to Wix
- Balancing the AI-generated starting layout with the original CampusCart branding and design intent from Figma

## Lessons Learned
- How to translate a Figma UI/UX prototype into a working no-code website
- Practical experience with Wix Stores for e-commerce features (products, cart, categories)
- Evaluating and switching no-code tools when one doesn't fit the project's needs
